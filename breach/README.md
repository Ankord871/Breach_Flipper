# Breach — прошивка для Flipper Zero

Форк [Momentum](https://github.com/Next-Flip/Momentum-Firmware). Развивается поэтапно,
чтобы каждый шаг можно было проверить и откатить.

## Этап 1 (готов)

| Что | Где |
|---|---|
| Обои главного экрана: анимация 128×64, 30 fps, красноволосая целиком по центру | `assets/packs/Breach/Anims/Teto_128x64` |
| Пак Breach выбран по умолчанию | `lib/momentum/settings.c` |
| Скрипт: любое видео, GIF или картинка в обои | `breach/tools/make_wallpaper.py` |
| Точная инструкция по смене обоев | [`breach/WALLPAPER.md`](WALLPAPER.md) |
| Превью раскладки главного меню в настройках | `applications/main/momentum_app/scenes/momentum_app_scene_interface_mainmenu_preview.c` |

## Как спланировать главное меню

1. Открой **Settings → Momentum → Interface → Mainmenu**.
2. В пункте **Menu Style** выбери стиль (Wii, DSi, PS4, Vertical, C64, Compact, MNTM, CoverFlow или List).
3. Открой **Preview Layout**. На экране схема раскладки именно этого стиля с номерами приложений.
   Кнопки влево/вверх и вправо/вниз листают приложения, выбранное подсвечено.
4. Нажми Back и поменяй порядок: **Item** выбирает приложение, **Move Item** двигает его,
   **Add Item** и **Remove Item** добавляют и убирают приложения.
5. Снова открой **Preview Layout** и проверь результат. Выбранное в **Item** приложение подсвечено и в превью.

Как заполняются экраны (так показывает и превью):

- **Wii**: 3 столбца по 2 ряда, заполняется сверху вниз, потом следующий столбец.
- **C64**: 2 столбца по 5 строк, сверху вниз, потом правый столбец.
- **Compact**: 2 столбца по 8 строк.
- **Vertical**: одна колонка, Flipper держат вертикально.
- **DSi, CoverFlow, PS4**: горизонтальная лента, выбранное приложение в центре (в PS4 слева).
- **List, MNTM**: список, видно три строки, выбранное в середине.

Превью схематичное: показывает порядок и положение приложений, а не точную копию экрана с иконками.

## Статус проверки

В этой среде нельзя скачать тулчейн Flipper, поэтому **полная сборка прошивки не запускалась**.
Проверено: анимация (кадры и `meta.txt`), синтаксис кода превью на заглушках API, сигнатуры функций
по заголовкам репозитория. Не проверено: сборка `./fbt`, показ на реальном устройстве,
скрипт упаковки в `breach/sd_ready` (нужен `pip install pillow numpy heatshrink2`).

Первая сборка: `./fbt` (или `./fbt updater_package`) и прошивка через qFlipper.
Если сборка выдаст ошибку, пришли её текст целиком, и я исправлю.

## Лицензия и апстрим

Momentum распространяется под своей лицензией, см. `LICENSE` в корне. В репозитории Momentum есть
`AGENTS.md`: мейнтейнеры запрещают отправлять им правки, написанные с помощью ИИ. Не открывай
pull request в апстрим Momentum с этими изменениями. Для собственного форка Breach это ограничения не создаёт.
