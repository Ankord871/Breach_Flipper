# Breach: как поменять обои Flipper

«Обои» главного экрана в Breach — это анимация 128×64 (1 бит) из asset-пака **Breach**.
Скрипт `breach/tools/make_wallpaper.py` превращает любое видео, GIF или картинку в такую анимацию.

## Один раз: что нужно установить

1. Python 3
2. ffmpeg (должен запускаться командой `ffmpeg` в терминале)
3. Библиотеки: `pip install pillow numpy heatshrink2`

## Способ 1. Без пересборки прошивки (быстро)

Все команды запускай из корня репозитория.

1. Положи видео в папку репозитория, например `my.mp4`.
2. Выполни:
   ```
   python3 breach/tools/make_wallpaper.py my.mp4 --name MyWall
   ```
   Скрипт сам выберет центральную область нужной пропорции и сделает анимацию на весь экран.
3. Появится папка `breach/sd_ready/asset_packs/Breach`.
4. Вставь SD-карту Flipper в компьютер и скопируй эту папку в `asset_packs/Breach` на карте
   (если там уже есть папка `Breach`, замени её).
5. Верни карту во Flipper. Открой **Settings → Momentum → Interface → Graphics → Asset Pack**
   и выбери **Breach**. Перезагрузи Flipper, если картинка не обновилась.

## Способ 2. Вшить обои в прошивку

Пак лежит в `assets/packs/Breach`, и скрипт обновляет именно его. После запуска скрипта
просто собери прошивку обычным образом, Breach выбран паком по умолчанию.

## Параметры скрипта

| Параметр | Что делает | Пример |
|---|---|---|
| `--name` | Имя анимации (только буквы и цифры) | `--name Night` |
| `--start`, `--end` | Какой кусок видео взять, в секундах | `--start 1 --end 4` |
| `--fps` | Кадров в секунду, 1–30 (по умолчанию 10) | `--fps 30` |
| `--crop x,y,w,h` | Какую область кадра взять, в пикселях видео | `--crop 0,80,480,300` |
| `--delogo x,y,w,h` | Стереть водяной знак в этом прямоугольнике | `--delogo 2,280,70,66` |
| `--layout` | `fill` растягивает кадр на весь экран, `center` вписывает картинку целиком по центру, `side` ставит её справа, слева надпись | `--layout center` |
| `--text` | Надпись слева при `--layout side` | `--text "MY FW"` |
| `--no-glitch` | Выключить глитч надписи | |
| `--mode` | `toon` (по умолчанию): чёрные контуры и точечный узор для цветных областей; `solid`: чёткие чёрные формы; `lines`: тонкие линии; `fs`: точечная фотография | `--mode solid` |
| `--threshold` | Порог тёмного: больше значение, больше чёрного (по умолчанию 140 для toon) | `--threshold 120` |
| `--invert` | Поменять чёрное и белое | |
| `--keep` | Не удалять другие анимации в паке Breach | |

Обои из этого репозитория (красноволосая из видео) собраны так:

```
python3 breach/tools/make_wallpaper.py video.mp4 --name Teto --start 0 --end 1.95 \
    --crop 0,80,480,300 --delogo 2,280,70,66 --layout center --mode lines --fps 30
```

## Советы

- Экран Flipper очень маленький, лучше всего выглядят контрастные рисунки и аниме-арт.
- Если картинка слишком чёрная или слишком светлая, меняй `--threshold` (110–190).
- Про 60 fps: у исходного видео 30 кадров в секунду, поэтому 30 — максимум, который имеет смысл (скрипт выше 30 не берёт). Каждый кадр занимает память Flipper, так что для длинных клипов снижай `--fps` или бери короче кусок: 2 секунды при 30 fps это около 60 кадров.
- Чтобы найти нужные координаты `--crop`, открой любой кадр в редакторе и посмотри размеры в пикселях.
  Формат такой: `x, y` — левый верхний угол, `w, h` — ширина и высота. Лучшая пропорция области — 2:1.
- Если что-то пошло не так, удали `Breach` с SD-карты и выбери в настройках пак `Default`.
